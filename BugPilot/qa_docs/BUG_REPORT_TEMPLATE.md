# Bug Report Template

**ID:** BUG-XXX  
**Title:** Describe the problem in one sentence.  
**Severity:** Low / Medium / High / Critical  
**Status:** Open / In Progress / Ready for Retest / Closed  
**Environment:** OS, browser and application version/build if known.

## Steps to reproduce
1. Start from a clear initial state.
2. Perform the action that triggers the problem.
3. Record what happens.

## Expected result
What should happen according to the requirement.

## Actual result
What happened during the test. Avoid guessing at the cause.
