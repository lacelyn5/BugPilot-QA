How to use BugPilot

A quick guide to connecting applications and keeping QA work in one place.

＋ Add project
01

Connect a project

First start the web application you want to test, either on your computer or on a reachable test/staging server. Then open Projects → Add project and provide its name and base URL.

Example: http://127.0.0.1:8001

Already have source code in a ZIP? Use Import project ZIP. You can set the URL after starting the app.

02

Create test cases

Select the project when creating a test case. Use HTTP automated for a simple GET check, or Manual for a workflow that needs a person to follow the steps.

For an HTTP case, set a relative path, expected HTTP status and optional text expected in the response. Example: /accounts/login/, status 200, text Login.

Create a test case →
03

Run tests and save results

Automated HTTP cases can be run from the test list or test detail page. Manual cases provide PASS, FAIL and ERROR buttons plus a notes field.

Every saved result appears in Run history, on the individual test's page, and in the overview dashboard. Automated checks record request details and duration; manual results record your notes.

Open test cases →
04

Track bugs

Use Report a bug to link an issue to a project. Add reproducible steps, expected and actual behavior, environment and severity.

Open any bug report to read it, or edit it to move its status from Open through retesting to Closed.

Manage bug reports →

Where is everything saved?

Projects, test cases, bug reports and run history are kept in BugPilot/db.sqlite3. Imported project files are stored in BugPilot/uploaded_projects/. You can manage records from the pages in the sidebar—there is no need to open the database directly.

For a backup, stop BugPilot and copy the database file. If you imported ZIP projects, copy the uploaded_projects folder too.

Import another project's ZIP

Open Projects → Import ZIP. BugPilot unpacks the source files and adds the project to your workspace.

For safety, BugPilot does not execute code from an uploaded archive. Start the project separately, then edit the project in BugPilot and enter its URL. This keeps source import simple without running unknown code inside the QA tool.
